# Catalogos maestros OM7

Esta carpeta almacena catalogos maestros importables del sistema OM7 Finance OS.

Inicialmente se usara para guardar el catalogo contable real en Excel, que servira como fuente oficial para importar y actualizar la estructura de cuentas contables.

Los archivos colocados aqui no deben eliminarse sin validar su reemplazo, porque funcionan como fuente de importacion y trazabilidad operativa del sistema.

Archivo esperado inicialmente:

```text
Catalogo de cuentas v1 12 mayo 26.xlsx
```
